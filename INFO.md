# Удалять можно только то, что появляется само при сборке и запуске. Остальное держит npm run dev и деплой.


## Можно удалить

**.vercel** — готовая сборка. Появится снова после npm run build.
**.tanstack** — кэш роутера. Появится снова при dev или build.
**artifacts** — пустая папка под сгенерированные картинки. К дереву не подключена.


## Оставить

**scripts** — через них идут dev, build и превью.
**server** — middleware продакшен-сборки (манифест и карточка для шаринга). Без него Nitro-сборка ломается.
**.grok/app-env.json** — его читает обёртка перед Vite и выставляет VITE_AUTH_ENABLED. Папки skills и references приложению не нужны: это инструкции для модели в песочнице Grok. Если проект больше не собираете там, их можно убрать, сам файл — нет.
**migrations** — сейчас база выключена, и 0001_auth.sql к дереву не применяется. Папка нужна, только если позже включите вход и Postgres. Пока можно не трогать.
**startup.sh** — нужен только песочнице Grok, чтобы поднять сервер после сна. На вашей машине приложение стартует через npm run dev. Удалять имеет смысл, только если в ту песочницу больше не возвращаетесь.


## src/lib — общая логика без разметки страниц. Страницы в src/routes и компоненты её отсюда импортируют.

Само дерево — пять файлов:

**project-tree.ts** — статичная карта проекта «silva»: папки, файлы, подписи страниц. Это данные, которые рисуются ветками, а не сканирование диска.
**tree-engine.ts** — геометрия: из узла карты считает ветки, углы, толщину и координаты для canvas.
**tree-store.ts** — состояние слайдеров (угол, глубина, длина, палитра, выбранный узел) через Zustand.
**palettes.ts** — цветовые схемы неба, ствола и листьев.
**cn.ts** — склейка CSS-классов Tailwind. Её берут кнопки и панели.
Ещё два файла нужны оболочке, не рисунку дерева:

**error-component.tsx** — экран, если страница упала. Его подключает src/router.tsx.
**preview-host-bridge.ts** — мост с превью Grok. В обычном браузере ничего не делает.
Остальное — заготовки шаблона. Дерево их не вызывает, вход и база сейчас выключены:

**db.ts** — доступ к Postgres (Neon) или локальному PGLite и прогон миграций.
**auth/** — вход, сессии, проверка пользователя. В корень страницы вшит только AuthProvider, чтобы оболочка шаблона собиралась.
**app-data/** — чтение календаря, почты и файлов пользователя через коннекторы Grok.
**multiplayer/** — WebRTC-комнаты для совместной игры.
**og/site.json** — название и тип карточки для шаринга («Silva»).
